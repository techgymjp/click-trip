# クリックトリップ（Click Trip）

歩いた距離だけ日本を旅する、位置情報ゲームのリバイバル作品です。

## あそびかた

1. **「移動距離を測る」** を押すと、前回押した地点からの実際の移動距離（GPS）が「移動できる距離」にたまります。
2. **レーダースコープ** を見て、行きたい方角へスワイプ。たまった距離をすべて使って、その方角へゲーム内を進みます。
3. 観光地は **2km 四方のマス**。ちょうど観光地のマスに着地できたら **観光地到着画面**（イラスト・解説文・クイズ）が開きます。
4. はずれたらレーダー画面に戻り、近くの観光地の方角と距離がわかります。また歩いて距離をためましょう。

- 距離は全部使い切るので、遠すぎるときは寄り道して三角形を描くように進むのがコツです。
- クイズは問いだけ。X や LINE で答えをみんなに聞いてみてください（`#クリックトリップ`）。
- 進行状況はブラウザ（localStorage）に毎回自動保存されます。設定画面から書き出し・読み込みもできます。
- ファミコン風のレトロな電子音 BGM（タイトル・フィールド・旅日記の3曲と到着ファンファーレなどのジングル）と効果音つき。音は設定画面または右上の「♪」でオン・オフできます。
- 日本語と英語に対応。端末の言語が日本語なら日本語、それ以外は英語で表示し、設定画面とはじめの画面で切り替えられます（観光地 2000 件の名前・解説・クイズも英訳済み）。
- GPS が使えない環境では「デモモード」（ボタンを押すたびにランダムな距離がたまる）で遊べます。

## 動かし方

ビルド不要の静的サイトです。位置情報 API は HTTPS（または localhost）でしか動かないので、GitHub Pages などで公開するか、ローカルでは次のように起動します。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## Android アプリ

Capacitor でゲームのファイルをアプリに同梱し、Android アプリにしています（パッケージ名 `jp.techgym.clicktrip`）。構成は JET STRIKE と同じです。

- `npm run build` で `www/` にゲームのファイルをコピー（広告の本番／テスト切り替えとバージョン表示を生成）
- `npm run android:sync` で Android プロジェクト（`android/`）に反映
- ビルドは GitHub Actions（`.github/workflows/android.yml`）が行い、動作確認用の APK（テスト広告）を Release `android-latest` に載せます。Secrets にアップロード鍵があれば、Google Play 用の署名付き AAB（本番広告）も作ります
- 動作確認用 APK の QR コード: `docs/apk-qr.png`（直接ダウンロード）、`docs/release-qr.png`（リリースページ）
- ストア掲載情報の下書きと画像: `docs/store/`

アプリだけの動き:

- 位置情報は Android の権限（アプリ使用中のみ）で取得し、端末の外には送りません
- 戻るボタン: 到着画面を閉じる → レーダーに戻る → アプリを終了
- シェアは Android の共有メニュー、セーブデータの書き出しは共有メニューで文字列として渡します
- 広告: 画面下にバナー（到着画面・はじめの画面を開いている間は隠す）。新しい観光地の到着画面を閉じたとき毎回インタースティシャル。はずれたときに「広告を見てやり直す」（リワード）で移動前の場所と距離に戻れます。本番の広告ユニット ID は `js/ads.js` の `production` に入れ、空の種類は出しません
- 歩きながら遊ぶゲームなので、画面の点けっぱなし（`FLAG_KEEP_SCREEN_ON`）はしていません

## 観光地データについて

国土交通省「国土数値情報（観光資源データ）P12」2014年版（全国約1.7万件）から、次の方針で 2000 件を選んでいます。

1. 種別（山岳、神社・寺院、温泉など）が付いた全国的な観光資源（約390件）はすべて採用
2. 残りは名称から観光地らしさを採点し、都道府県ごとに偏らないよう補充（同じ 2km マスに重なるものは除外）

元データの都道府県ごとの収録数に差があるため、宮城・愛知・福井・神奈川・香川など一部の県は件数が少なくなっています。
座標は資源の範囲（点群・線・面）のうち重心に最も近い点を代表点としています。

解説文・クイズ・イラスト指定はゲーム用に作成したもので、最新の現地情報とは異なる場合があります。
